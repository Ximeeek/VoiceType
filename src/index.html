DEV

Ultra-lekka, hybrydowa aplikacja desktopowa do dyktowania mowy i tłumaczenia w czasie rzeczywistym (silniki lokalne oraz chmurowe STT).

Rdzeń aplikacji Rust
Tauri v2 + Tokio Async
Silnik główny napisany w Rust dla maksymalnego bezpieczeństwa pamięci, zoptymalizowanego zużycia CPU oraz natychmiastowego startu bez ciężkiego środowiska Electron.
Audio DSP & Silero VAD
16kHz Ring-Buffer Filtering
Przetwarzanie audio za pomocą biblioteki CPAL z wbudowaną filtracją szumów oraz detekcją głosu (Voice Activity Detection) Silero z dokładnością 30ms.
Win32 UI Automation
SendInput + Focus Detector
Bezpośrednie wstrzykiwanie znaków Unicode do aktywnego pola tekstowego w dowolnej aplikacji Windows z buforem bezpieczeństwa Clipboard fallback.
Macierz 9 Silników STT
Local + Cloud Engines
Pełna swoboda wyboru pomiędzy silnikami lokalnymi (Vosk, Sherpa-ONNX, Whisper, Faster-Whisper CUDA) a dostawcami chmurowymi (Deepgram, AssemblyAI, OpenAI, Google, Azure).
Pisanie Na Żywo & Kontrola
Streaming & Hotwords
Wpisywanie tekstu w czasie rzeczywistym podczas mówienia, własne frazy aktywujące i zatrzymujące bez użycia rąk oraz opcjonalny Auto-Enter.

Ostrzeżenie: Wysokie koszty API w chmurze

Wybrany silnik chmurowy (OpenAI Whisper) nie obsługuje natywnego strumieniowania audio w czasie rzeczywistym. Pisanie na żywo wymaga ciągłego wysyłania fragmentów nagrania przez zapytania API co 1.5–2 sekundy.

Włączenie pisania na żywo dla tego silnika chmurowego drastycznie zwiększa liczbę zapytań API i może wygenerować znacznie wyższe opłaty na Twoim koncie chmurowym!
